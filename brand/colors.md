# Colors

Black field. One green. No teal, no navy. Void is tinted — never `#000`.

| Token | Hex | Use |
| --- | --- |
| Void | `#0B0F0C` | Slide chrome, UI canvas |
| Phosphor | `#3DFF8A` | Action, `P(adopt)`, one emphasis |
| Dim | `#163226` | One surface lift, hover |
| Fog | `#C8D5CC` | Body on void |
| Mute | `#7A9586` | Eyebrows, sources |
| White | `#F4FBF6` | Titles on void |
| Rule | `#1F3A2E` | Hairline borders |

Phosphor is the only saturated color on a frame.
Fog and Mute do not sit on Phosphor.
