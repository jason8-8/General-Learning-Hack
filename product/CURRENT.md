# Current product contract

Updated 20 September 2026. This is the canonical implementation state. Earlier BUILD, HANDOFF, PROJECT and learning-loop plans remain useful history, not current acceptance claims.

## Decision

Help an early-stage founder decide **which assumption deserves a real customer test before building**. The travelling consumer is the example respondent; the founder is Hindsight's user.

The wedge is a saved decision record: source evidence, explicit assumptions, a preserved baseline, actual model results, and a declared next test. This is the demo emphasis, not a claim of unique intellectual property or validated prediction.

The main demo runs offline using bundled files. It requires no API credentials. Do not start new model or paid-media runs for rehearsal.

## Proof path

1. Show the proposed travel offer and why free alternatives matter.
2. Open a saved competitor summary and its primary source link.
3. Freeze the selected scenario. Change exactly one of price, offer or audience.
4. Show the preserved baseline and explicit assumption boundary.
5. Reveal the actual 20-profile pilots, including their uniform outcomes and different offer.
6. Declare a test with real travellers, write a decision rule, and export the receipt.

The feedback loop exists as an illustrative workflow in the lab. No real evidence was used to demonstrate improvement. Do not narrate it as a completed validation cycle.

## Known limits

- Research uses a bounded, saved source set and keyword retrieval. It is not autonomous, broad web research.
- Changing retrieval does not regenerate authored answers.
- The scenario's concept ranking is encoded in its assumptions. Lower price mechanically increases eligible choices; neither result validates demand.
- Equal groups of 200 do not establish population shares.
- A unanimous model pilot may expose model or prompt limitations. It does not prove customers will all refuse.
- The old probability blend is not a validated probability and can behave non-monotonically. It is isolated from the presentation and not a launch decision tool.
- Baseline and note persist only within the tab until exported. No account, cloud database or deployment is implied.
