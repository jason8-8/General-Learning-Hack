The stack, the RAG boundary, and MiroFish +

Presentation: HTML, CSS, JavaScript and your Space Grotesk / Space Mono fonts. Python serves the app and JSON dataset. No cloud services are needed.

Retrieval-augmented generation (RAG): retrieve relevant source passages, add them to the profile and offer, then ask a model for a grounded answer. This demo implements keyword retrieval over sentence chunks. It uses authored answers in place of the generation step, with no embedding model or vector database.

Real experiment lab: MiroFish-local extracts a SQLite knowledge graph and produces profile seeds. OASIS handles interviews, Ollama runs the local model, and Python stores raw answers and calculations. Its real pilot results are preserved separately. This presentation's prices and opinions did not come from that engine.

How we got these numbers: 1,000 fictional scenarios, in five groups of 200. Explicit eligibility and price-response assumptions are in the scenario controls. No customer data, inferred market size or accuracy claim. Download the fixture to inspect every value.
